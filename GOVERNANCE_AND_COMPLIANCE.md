## 1. Executive Summary & Algorithmic Classification
## 1. 執行摘要與演算法分類定性

### 1.1 Algorithmic Determinism vs. Generative AI
### 1.1 演算法確定性與生成式 AI 之定性區隔

**[English]**  
The Lawgic platform (`jackylawck.github.io/Lawgic`) is an esports-grade procedural logic generation and psychometric measurement platform. The platform explicitly clarifies that **it does not deploy, embed, or invoke autonomous black-box neural networks, Large Language Models (LLMs), or stochastic generative machine learning models**.  
All 18 puzzle engines (e.g., Kakuro, Sudoku, Maze, Slitherlink, Hashi) operate strictly on:
1. Deterministic seeded Pseudo-Random Number Generation (PRNG via Mulberry32 algorithm);
2. Constraint Satisfaction Problem (CSP) solvers;
3. Pure symbolic deductive reasoning logic (Forward Checking / MRV heuristics).

**[繁體中文]**  
Lawgic（羅輯）平台為競賽級程式化邏輯生成與認知心理計量平台。本項目特此明確聲明：**系統未部署、未嵌入、亦未調用任何自主黑箱神經網絡、大型語言模型（LLM）或隨機生成式機器學習模型**。  
全站 18 款核心謎題引擎（如數和、數獨、迷宮、單迴路、數橋等）均嚴格構建於：
1. 確定性種子偽隨機演算法（Mulberry32 演算法）；
2. 約束滿足問題（CSP）回溯剪枝求解器；
3. 純符號因果推導階梯（前向檢驗 / 最小剩餘值優先啟發式）。

## 3. Zero-Trust Cryptographic Proof & Client-Side Integrity
## 3. 零信任密碼學存證與客戶端完整性防護

**[English]**  
To safeguard competitive integrity without central telemetry or invasive tracking, Lawgic implements a zero-trust cryptographic signature mechanism:
* **Deterministic Proof**: Submission digests use client-side W3C Web Cryptography API (`SHA-256`) binding the `submissionId`, `puzzleId`, `tier`, `seed`, `timeSpentSec`, and physical canvas/hardware environment metrics.
* **No Telemetry**: No user telemetry, voice, biometric, or behavioural analytics are transmitted to centralized servers. All storage resides under user ownership (`localStorage` / `IndexedDB`).

**[繁體中文]**  
為在不依賴中央監控與侵犯性追蹤的前提下保障競賽公信力，Lawgic 實作零信任密碼學存證架構：
* **確定性存證**：賽事提交校驗碼基於 W3C 原生 Web Cryptography API（`SHA-256`），強制綁定題目編號、階級、隨機種子、解題耗時及 Canvas 渲染環境特徵。
* **零遙測監控**：不收集、不傳輸任何生物特徵、語音、鍵盤側寫或個人識別紀錄。所有數據均歸用戶本地掌控（`localStorage`）。
